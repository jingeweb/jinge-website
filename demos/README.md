# 示例来源

这些示例来自同级 jinge-demos 仓库，保留原实现与文件结构，以独立 iframe 在官网运行。每个示例页面显示本地快照源码，并链接上游仓库。

上游：https://github.com/jingeweb/jinge-demos 。作者：Yuhang Ge。示例包声明许可证为 ISC；框架依赖的许可证以各包为准。更新示例时同步源码与 manifest，再执行完整构建和浏览器测试。

官网适配：统一占位节点为 app，第三方图表使用模块化导入、响应式尺寸与销毁清理；新增 router-navigation 展示路由能力。交互测试改编自 jinge-demos/test/e2e，保留原有场景。
