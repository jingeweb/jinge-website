## 編譯器配置

```ts
jingeVitePlugin({ intl: true });
```

啟用後，編譯器處理 `t()` 呼叫與對應模板監聽。國際化不僅是執行時字典查詢，還包括編譯時文本轉換。

## 在元件裡使用

```tsx
import { t } from 'jinge';

<p>{t('你好，{name}！', { name: state.name })}</p>;
```

支援引數與富文本。模板中的翻譯會在切換語言後更新，元件初始化時計算的普通字串不會自動重新執行。

## 初始化語言字典

```ts
import { intlInit, intlSetLocale } from 'jinge';

import zh from './intl/zh';

await intlInit({
  defaultLocale: 'zh',
  dicts: { zh },
  dictLoader: async (locale) => {
    if (locale === 'en') return (await import('./intl/en')).default;
    throw new Error(`Unsupported locale: ${locale}`);
  },
});

await intlSetLocale('en');
```

## 工具鏈

`jinge-compiler` 提供 `intl-extract` 與 `intl-compile` CLI，用於提取文本和生成字典。執行 `pnpm exec intl-extract --help` 與 `pnpm exec intl-compile --help` 檢視當前版本引數。完整檔案結構、字典與切換行為見[國際化示例](/examples/i18n/)。
