## 编译器配置

```ts
jingeVitePlugin({ intl: true });
```

启用后，编译器处理 `t()` 调用与对应模板监听。国际化不仅是运行时字典查找，还包括编译时文本转换。

## 在组件里使用

```tsx
import { t } from 'jinge';

<p>{t('你好，{name}！', { name: state.name })}</p>;
```

支持参数与富文本。模板中的翻译会在切换语言后更新，组件初始化时计算的普通字符串不会自动重新执行。

## 初始化语言字典

```ts
import { intlInit, intlSetLocale } from 'jinge';

import zh from './intl/zh';

await intlInit({
  defaultLocale: 'zh',
  dicts: { zh },
  dictLoader: async (locale) => {
    if (locale === 'en') return (await import('./intl/en')).default;
    throw new Error(`Unsupported locale: ${locale}`);
  },
});

await intlSetLocale('en');
```

## 工具链

`jinge-compiler` 提供 `intl-extract` 与 `intl-compile` CLI，用于提取文本和生成字典。运行 `pnpm exec intl-extract --help` 与 `pnpm exec intl-compile --help` 查看当前版本参数。完整文件结构、字典与切换行为见[国际化示例](/examples/i18n/)。
